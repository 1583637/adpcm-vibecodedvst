## Build Instructions

### Requirements
- CMake 3.25+
- C++17 compatible compiler (GCC 10+, Clang 12+, MSVC 2019+)
- JUCE 8 (fetched automatically via CPM/FetchContent)

### Build Steps

```bash
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release
```

The plugin binary will be in `build/ADPCMDecay_artefacts/Release/VST3/`

### Validate

```bash
pluginval --strictness-level 5 --validate "build/ADPCMDecay_artefacts/Release/VST3/ADPCMDecay.vst3"
```

### Install

Copy the .vst3 folder to:
- **macOS:** `/Library/Audio/Plug-Ins/VST3/`
- **Windows:** `C:\Program Files\Common Files\VST3\`
- **Linux:** `~/.vst3/`
